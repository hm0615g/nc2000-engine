## Design Goals

1. **Contains the Nash Equilibrium (`vc-kodoku-nash-a`, 4 teams)**:
   - Shell A (`vc-kodoku-nash-a`, 4 variants, **Nash · 進化論生まれ**): `apex-c08-surgical-142` (30%), `red-v10-s1105-r2-s0142` (25%), `apex-c04-bug-3atkstar-boomgen` (25%), `red-v10-s1105-r1-s0148` (20%) (Snorlax55 / Cloyster50 / Gengar50 / Heracross50 / Marowak50 / Starmie50)
   - Classic Multi-Variant Cluster (`vc02`, 3 variants): `sample-08`, `rental-cban-6`, `hc75-3rd-bean` (Zapdos55 / Miltank55 / Snorlax50 / Cloyster50 / Exeggutor50 / Machamp50)
2. **Comprehensive Archetype Coverage**:
   - Covers major NC2000 archetypes across Snorlax55, Zapdos55, Tyranitar55, Raikou55, Tauros55, Porygon2-55, Alakazam55, Marowak55, Poliwrath55, Entei55 Sunny Day (`hc75-top8-tsuru`), Dragonite55 + Kingdra55 (`sample-22-orig`), Misdreavus + Houndoom Perish trap (`sample-14`), and Smeargle Spore/Baton Pass + Nidoking55 (`sample-09`).
3. **Meaningful Diversity (No Non-Nash Redundant Shells)**:
   - Outside the 2 Nash shells, every one of the 19 clusters is a distinct 6-Pokémon shell (`size: 1`). Near-duplicate non-Nash shells with similar play feel were pruned.
4. **Novel Evolved Archetypes (`進化論生まれ`, 4 teams in addition to Nash Shell A)**:
   - `red-v5-r1-s0097` (`vc-kodoku-evo-raikou`): Raikou50 / Cloyster50 / Snorlax50 / Tyranitar55 / Heracross55 / Machamp50
   - `deme-r1-00-s0030` (`vc-kodoku-evo-ttar-raikou`): Tyranitar55 / Skarmory50 / Marowak50 / Snorlax50 / Raikou55 / Suicune50
   - `red-v10-s1105-r2-s0155` (`vc-kodoku-evo-stall`): Blissey50 / Skarmory50 / Marowak50 / Snorlax55 / Miltank55 / Suicune50
   - `sib-r1-n4-red-v6-r1-s0064-s07` (`vc-kodoku-evo-wobb`): Gengar50 / Wobbuffet50 / Moltres50 / Cloyster50 / Snorlax55 / Zapdos50
5. **Competitive Viability**:

## Normalization Rules

- Only Pokémon sets with no Physical moves (`Hidden Power` counts by its
  computed type) are modified.
- Those sets get `evs.atk = 0`, `ivs.atk = 6` (Gen 2 Attack DV `3`, which is
  the lowest female-compatible Attack DV for 50/50 gender species while keeping
  a `0` Attack stat), and `gender = "F"` when the species allows it.
- In multi-member clusters where a sibling team requires `"M"` on the same
  species (e.g., `Cloyster` with `Explosion` in `vc-kodoku-nash-a`), `"M"` is
  preserved and `ivs.atk = 18` (Gen 2 Attack DV `9`, the lowest male-compatible
  DV for 50/50 gender species) is used so the cluster shares an identical Team
  Preview signature.
- Moves, items, levels, non-Attack stats, and Hidden Power types are preserved.
- Applied changes in this release:
  - `18` teams updated
  - `32` sets updated
  - `7` gender fields changed to `"F"`
